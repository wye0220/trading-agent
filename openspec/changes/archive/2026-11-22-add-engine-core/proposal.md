# Proposal

## Why

阶段 1 能按因果规则读行情，阶段 2 能判断信号，但两者之间还没有东西把信号变成纸面订单、模拟成交、算盈亏。提示词包的 Prompt 3（引擎核心）补上这一层：事件时钟、通用订单意图执行器、成交模型、风控边界和给模型用的上下文构建器。`scan`（阶段 4）和 `replay`（阶段 5）都只是在它外面包一层，所以它要先定下来。阶段 1–3 验收后，表结构、状态枚举和引擎接口进入冻结。

## What Changes

- 新增 `src/trading_agent/engine/`，只提供可被 `scan` 和 `replay` 共同调用的函数和事务封装，**不新增任何 CLI 功能**。
- **事件时钟**：时钟只前进；决策只用已收线且已可见的数据；区分信号 K 收盘、数据可用、挂单激活和触价；迟到的数据只影响之后的决策。
- **通用成交模型**（单一实现，带版本号）：
  - `STOP_LIMIT_NEXT_BAR`：`ARMED → TRIGGERED → FILLED` 或 `EXPIRED`，成交价不越过限价。
  - `MARKET_NEXT_OPEN`、`LIMIT_RETRACE` 各自的成交规则。
  - 成交后保护止损和固定目标立即生效、成对撤销；三种通用目标描述在成交后定价。
  - 有 1 分钟线时用它定位盘中先后；只有整根 OHLC 且先后不明时按止损优先，并打上歧义标记。
  - 跳空、入场当根止损、截止强平、同价位原子反手、缺失行情不造成交。
- **风控**：每手计划风险；纸面评测固定 1 手、按 R 计量、不过账户预算门禁；人工计划按预算算手数；真实账户的日损、预留和两次止损停手按账户和交易日共享，跨策略有效。
- **版本绑定**：每轮按四维 scope 加载一次版本元组；新信号用当前版本，已排队的订单和旧仓位保留绑定的版本。
- **上下文构建器与 JSON schema**：给 Claude 的只是裁剪后的结构化事件，有 token 预算；`schemas/` 下定义六个输出 schema；校验失败的输出丢弃并记录；模型不可用时确定性流程照常运行，解释请求进重试队列。
- **逐步运行器**：把"推进行情 → 算特征 → 调策略 → 风控 → 挂单"串成一步，幂等，可回放。
- 新增配置 `config/risk.yaml`（费用、滑点、研究风险单位、账户限额）和 `config/engine.yaml`。**费用、单笔预算、日损上限、最大手数都留空，由你填写**；没填之前纸面评测照常，按"费用未配置"标记，人工预算一律不放行。
- 新增运行库 migration `0002`：纸面仓位、引擎运行记录、解释请求队列、账户风险日记录，并给纸面订单表补几列。
- 新增文档 `docs/engine.md` 和成交测试向量 `tests/vectors/fills/*.yaml`。

不在本次范围：`scan` 接入策略、`plan`、`watch`、人工成交导入（阶段 4）；回放报告和基线（阶段 5）；真正调用 Claude（阶段 4、10）。

**仍然不在真实历史上运行策略。** 引擎的验收全部用合成数据和手写向量。

## Capabilities

### New Capabilities

- `engine-event-clock`: 事件时钟、数据可见性、订单的时间窗口、逐步运行与幂等。
- `paper-fill-model`: 纸面订单的状态机和成交规则，含歧义标记、强平、反手。
- `risk-controls`: 每手风险、手数、纸面与真实账户两个风险域的隔离、日损与停手。
- `version-binding`: 版本元组的加载与绑定。
- `llm-context-contract`: 给模型的上下文裁剪、输出 schema 校验、解释请求的重试队列。

### Modified Capabilities

- `runtime-storage`: 新增引擎所需的表和列。

## Impact

- **代码**：新增 `src/trading_agent/engine/`、migration `0002`、`schemas/*.json`、两个配置文件、文档、成交向量。阶段 1、2 的模块只在需要时增加只读接口，不改已有行为。
- **依赖**：新增 `jsonschema`（校验模型输出）。
- **数据**：运行库多几张表。发布库仍然不写。
- **契约冻结**：本阶段验收后，表结构、状态枚举和引擎公共接口（含 `StrategyProvider` 与 `OrderIntent`）进入 `FROZEN_CONTRACT`，之后的改动要走编号 migration 并重跑全部既有测试。
- **需要你填写**：`config/risk.yaml` 里的费用、滑点预算、研究风险单位、单笔预算、日损上限、最大手数。
